Indexers

API keys are sealed with the instance key and are never returned over HTTP — not even here. Leave the field blank when editing to keep the existing key.

Metadata provider

TMDB says what a series contains, what a film is called, and supplies the artwork. Paste the API Read Access Token from TMDB's API settings page. It is checked against TMDB before it is stored, sealed with the instance key, and never shown again — not here, not anywhere.

Subtitles — OpenSubtitles

A file's subtitle is fetched from OpenSubtitles.com, which needs an API key of your own: create one under API consumers in your OpenSubtitles profile. An account's username and password may be added too; signed in, an account gets more downloads a day. The key and the password are sealed with the instance key and never shown again. Languages are two-letter codes, like en, fr.

Notifications

What happens here, sent to a Discord channel: a flood of denials, a password accepted with the wrong authenticator code, an account waiting for approval, backups or the tunnel failing. In Discord, open the channel's settings, then Integrations and Webhooks, create a webhook and copy its link. The link is the key to posting in your channel: it is checked with Discord before it is kept — a check that posts nothing — stored sealed with the instance key, and never shown again.

Network

Where each subsystem's traffic goes, and whether the tunnel downloads depend on is up. The policy is the configuration file's, changed there and applied by a restart — except the SOCKS5 proxy below, which asks for your password and an authenticator code, is announced on Discord, and also applies on restart.

Per subsystem

SOCKS5 proxy

A proxy such as NordVPN's carries the ticked traffic instead of this machine's own address. If it cannot be reached, that traffic stops; it never goes direct. A proxy carries TCP only, so downloads run without DHT or uTP.

Send through it

Proxied indexer searches need metadata and subtitles proxied too — a lookup says what this instance holds as plainly as a search says what it wants — and cannot reach an indexer on your own network, which the proxy is not on.

Getting started

What this instance needs to find, fetch and describe what you want. Each step is an ordinary setting on its own tab and can be changed at any time; skip any you do not need.

Music comes from MusicBrainz and books from Open Library. Neither needs an account or a key.

Accounts

Suspending an account revokes its sessions, its API tokens and any invites it issued, and takes effect on that account's next request. Reactivating restores the access somebody had — an account that never enrolled an authenticator goes back to awaiting_mfa, not to active.

Create an account

You never learn their password: you get a link that sets one, usable once, for three days. Then they sign in and enroll an authenticator.

Roles

What each role may do. Admin holds everything and is not editable; admin.system, admin.users and admin.network stay Admin's. A change applies to every holder, and every token they issued, from their next request.

Account requests

Approving a request creates the account in awaiting_mfa: it cannot do anything until the person enrolls an authenticator.

Invites

Your sessions

Revoking a session takes effect on its next request — sessions are server-side records, not self-contained tokens, so there is nothing left holding authority once the record is gone.

API tokens

A token can never exceed your own permissions, and its scope is re-checked against your current role on every request — if your role is narrowed, every token you issued narrows with it. Tokens cannot change credentials, manage sessions or mint further tokens.

Migrate from Radarr

This brings across the part of a Radarr library that is expensive to recreate: which folder is which film. Add your existing movie folder as a root folder and scan it first, then match the scanned items to Radarr's identities here. Nothing is moved or renamed.

Audit log

Everything this instance recorded about who did what: sign-ins, denials, account and role changes, every grab — a person's or automatic acquisition's — and every change to settings, newest first. Nothing here can change or remove a line. Addresses, user agents and details are shown as they were recorded, and much of that was written by whoever made the request.

Scheduled tasks

A task never runs concurrently with itself. Triggering one that is already running is refused rather than queued.

Health

Recent log records

What this process has written since it started — the last thousand records, redacted as the log output is. The host's log is the history.

Backups

Each backup is a snapshot of the database that passed SQLite's own checks, encrypted with a passphrase derived from the master key, and decrypted again to confirm it before it was kept. Without the master key a backup is unreadable — so keep the key somewhere other than this host, and copy the backups somewhere other than this disk.

Nothing here downloads or restores a backup. Copy the directory above off this host with your own tools. To check a copy, run cmediastack -verify-backup FILE on the host; to restore one, cmediastack -restore-backup FILE -restore-to PATH, which writes a new database file and says how to put it in place.
