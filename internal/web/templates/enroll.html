Set up your authenticator

Every account on this instance needs a second factor. Until yours is set up, this page is the only thing you can reach.

  1. Open your authenticator app — Google Authenticator, Authy, Aegis, 1Password, anything that does TOTP.
  2. Scan this code.

    On a phone, tap here instead and the app opens with the key already filled in.

    Can’t scan it? Enter the key by hand

    In your app choose add account, then enter a setup key (some call it "manual entry").

    Account name , type time-based, 6 digits, 30 seconds — the defaults everywhere.

  3. Type the six-digit code it shows.

Save your recovery codes

These are shown once and are not recoverable. Each one signs you in exactly once if you lose the authenticator. Store them somewhere that is not the device running the authenticator.
